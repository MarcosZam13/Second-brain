## Definition of Done

- [ ] Code implemented and follows the repo's best-practice skills (`.agents/skills/`)
- [ ] Tests (unit + at least one E2E case if the story touches a user-facing flow)
- [ ] PR opened following the `GITFLOW.md` format and approved
- [ ] QA validated the happy path + at least one negative/boundary case (see `qa-testing-practices`)
- [ ] `security-reviewer` run if the story touches auth, role-based permissions, input, or secrets
- [ ] `ARCHITECTURE.md` updated if the story changes an architecture decision
